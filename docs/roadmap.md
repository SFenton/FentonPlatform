# Roadmap

- Maintain measured consumer compatibility records and add performance baselines
  only after matched, independently recorded runs.
- Obtain independently approved component budgets and baseline-update rules;
  descriptive simulator measurements do not authorize performance promotion.
- Qualify repeatable final-source benchmark completion and the full Apple
  form-factor/accessibility matrix on healthy, available simulator hosts.
- Obtain qualified consumer landing review, current CI and full-matrix evidence
  for the draft Apple proposals; local pilot passes do not authorize promotion.
- Qualify experimental Windows/Android UI, accessibility, lifecycle and
  performance before consumer architectural adoption or package publication.
- Resolve recorded platform dependency license-review items before publication.
- Establish a separately authorized trusted isolated admission boundary.
- Obtain authorized private-consumer CI/authentication access; none is configured
  for this repository.
- Qualify explicit external host grants, usage accounting and a bounded live
  model-launch pilot before enabling the currently disabled host adapter.
- Measure decision questions with separately approved data scope, budgets,
  held-out labels and provider-specific calibration before leaving shadow mode.
- Qualify portable Windows process-tree ownership with a Job Object adapter;
  unsupported execution must continue to fail closed.
